## 工具栏整体不显示 → 根因定位与修复（同一晚）
- 用户澄清：“工具栏整个都没显示”（非画廊/进度条）。
- 关键事实：用户配置 `QuickView.ini` 不在 git 跟踪内（位于 %APPDATA%/QuickView/QuickView.ini），
  所以 git 恢复到 c952293 不会还原 ini 设置。
- 根因：ini `[View] LockBottomToolbar=0`。代码默认值为 1（main.cpp:4618 GetPrivateProfileIntW(...,1,...)），
  且 main.cpp:6585 `g_toolbar.SetPinned(g_config.LockBottomToolbar)` 据此驱动工具栏钉住/常显。
  设为 0 → 底部工具栏变为自动隐藏，平时完全不可见，仅鼠标移到窗口底部热区才出现 → 表现为“工具栏整个不显示”。
- 处置：停止进程（无运行中实例）→ 将 `LockBottomToolbar` 改回 `1` → 重新启动 EXE。
  该设置只影响工具栏常显/自动隐藏，不涉及其他功能；若用户偏好自动隐藏可改回 0（但需排查悬停不弹出的真正 bug）。
- 结论：代码 c952293 本身无问题；异常由未跟踪的 ini 被改成 LockBottomToolbar=0 引起（疑似其他 AI 改动或误改）。
