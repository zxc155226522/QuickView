# 2026-07-31 工作记录

## CDR 解码加速(看图软件 Zhai.PictureView)

### 根因(基于 cdr_debug.log 实测)
- CDR 慢不是 UI 卡死(7/30 已修),而是 `cdr2xhtml.exe` 把**内嵌高分辨率照片**的 CDR 转成 **45MB~202MB 巨型 SVG 文本**。
- 首次打开每张:进程启动+转换+管道读大文本+Substring/Regex+**Skia 解析 45~200MB SVG** ≈ 2~4 秒。
- 即便命中 SVG 缓存,**仍要 Skia 重复解析巨型 SVG** → 回看仍 0.5~1 秒。
- SVG 缓存容量仅 20 条,大目录滚动超 20 张又 MISS 重转换。

### 本次修复(CdrDecoder.cs + Folder.cs)
- 新增 **BitmapSource 渲染结果缓存**(键=`文件名|修改时间|目标尺寸`,上限 50):命中跳过 Skia 巨型 SVG 解析 → 回看/缩略图秒开。
- SVG 缓存 20 → **100**,减少大目录重复 cdr2xhtml 转换。
- `ExtractSvg` 去 Regex,改 `string.Replace("xmlns:svg=", "xmlns=")` 省 200MB 正则开销。
- 新增 `CdrDecoder.PreloadSvg`;`Folder.LoadAsync` 末尾后台 `Task.Run` 遍历 `.cdr` 预转换 SVG(受 CancellationToken 控制),让首次铺开免等转换。
