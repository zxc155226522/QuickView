## TIF 解码"同步"澄清
- 用户称原项目"更新 TF 解码更快"，澄清后 TF 实为 **TIF（TIFF）**。
- git 事实：origin = `github.com/zxc155226522/QuickView.git`；两次 `git fetch` 后 `origin/main` 仍停在 `35c9096`；本地 HEAD `92e0fc4` 领先上游 6 个提交；`HEAD..origin/main` 为空 → 上游无任何比本地更新的提交，亦无"新 TIF 解码"提交。
- TIFF 解码为**自研 MiniTiff**（非 libtiff）。已合入的提速项（均在 35c9096 之前，本地已含）：
  - `47a5402` SIMD 16-to-8 bit TIFF downsampling
  - `3fdcbce` 未压缩 TIF 预览跳采读（按 targetPx 步长采样行）
  - `0850a14` MiniTiff 预览降分辨率 IFD 选择
  - `2232505` MiniTiff CMYK 接入 ICC 精确转换
- `HeavyLanePool.cpp:1346` 注释：TIFF 有时走 WIC、有时走 MiniTiff，存在双路径调度。
- 结论：github 无可同步的"新 TIF 解码"；用户看到的"新提交"应为历史已有优化 commit。下一步若用户能提供具体 commit 链接/hash，再 fetch 比对；若确为 35c9096 之后新提交，按规范（结构化计划 + 改前/改后 git 备份）同步。

## CDR 预览模糊修复（22:08 起）
- 用户反馈：CDR 看图很糊；导出高清 PNG 再放大不糊。纠正了"渲染器(resvg vs D2D)问题"的误判。
- 真正根因：预览的 resvg 栅格化走 `renderSvgViaResvg`(main.cpp)，`maxDim=4096` 且 `QvRasterizeSvgFrameToBgra` 的 zoom 被锁死"只缩小不放大"→ 只出固定 4096px 位图，缩放全靠 D2D 线性拉伸 → 放大糊。导出 PNG 走位图 LOD 管线(`ComputeDesiredBitmapSurfaceSize` 按 fitScale×zoom 重解码到显示分辨率)→ 放大始终清晰。
- 修复（已编译通过并启动，git: 07bd9f9 备份前 / 2754d89 修改完成）：
  - `ImageLoader.h/.cpp`：`QvRasterizeSvgFrameToBgra` 增 `targetW/targetH`(>0 时按目标像素渲染，允许 zoom>1)；`QvRasterizeSvgResvg` 上限 8192→16384。
  - `ImageResource.h`：resvg 资源加 `isResvg` / `resvgSrc`(SVG源) / `resvgRasterW/H`，Reset/Clone 同步。
  - `main.cpp`：`renderSvgViaResvg` 按 `ComputeSvgSurfaceSize`(整图随缩放尺寸)渲染并保存 SVG 源；`RenderImageToDComp` resvg 分支尺寸变化>64px 时重栅格化，标准路径 1:1 绘制；`TryUpgradeBitmapSurface`/`RefreshSvgSurfaceAfterZoom` 对 resvg 也触发。复用了 D2D 矢量路径相同的表面尺寸计算与 DComp 变换管线，故尺寸/位置与矢量路径一致。
- 验收：用户需打开 CDR 肉眼确认清晰度（程序已启动）。

## 编译环境注意（重要，可复用）
- `看图软件编译并启动.ps1` 在 cmake 配置阶段会跑 vcpkg install，且强制走代理 `http://127.0.0.1:7890`。该代理 TCP 端口虽通，但实际无法出网 → vcpkg install 卡约 2 分钟超时失败（后台任务表现为 2m1s "failed"、无输出）。
- 绕过法（依赖已装于 `out/build/Release-LTO/vcpkg_installed` 630M）：重建 junction `E:\qv_build_tmp -> E:\项目\看图软件`（New-Item -ItemType Junction），把 CMakeCache 的 `VCPKG_MANIFEST_INSTALL:BOOL` 改为 OFF，刷新 `build.ninja` 时间戳，再用 `cmake --build out/build/Release-LTO --config Release` 直接增量编译（不触发 vcpkg）。LTO 单文件编译较慢(约2-3分钟)。
- PowerShell 工具内禁止调用 cmd.exe；`*>` 全流重定向偶尔不落盘，改用 `| Out-File -Encoding utf8` 更稳。
