## 磁盘缓存方案实现 + 验收（提交 9343995 @ 10:06）

用户 08-14 凌晨改主意：引入持久化磁盘缩略图缓存（上限 1G LRU），10s 硬放弃**只放弃该慢请求**（不杀服务器进程），大文件车道多线程。

### 改动清单
- 新增 `QuickView/ThumbDiskCache.h/.cpp`：持久化 BMP 缩略图缓存；key=normalize(path 盘符大写)+mtime+size+cx，FNV-1a 64 位 hex；`m_capBytes=1GB`，`EvictIfNeeded` 按 LastWriteTime 删最旧（每调上限 400 删）。Get 校验文件 stat+大小上限，损坏即删；Put best-effort。
- `ThumbnailProvider.cpp`：GetThumbnail 入口先查磁盘缓存，命中即 `ComposeSquareThumbnail` 秒回（跳过管道）；WatchdogWorker 与同步回退在 `PipeResult::Ok` 时 `Put` 持久化（修复旧版超时丢弃位图 → 滚回秒出）；`kPipeTimeoutMs` 60000→10000（单请求 10s 硬放弃）。
- `ThumbnailWorker.cpp`：`kLargeThreads=2`（此前大文件车道单线程；现 TLS fz_context + 每 worker 独立 CImageLoader 已安全）。
- `CMakeLists.txt`：两个 target 均加入 ThumbDiskCache。

### 编译期障碍与修复
- 首编 3 错：`ThumbDiskCache.cpp` 缺 `#include <strsafe.h>`（StringCchPrintfW 未声明）；`ThumbnailProvider.cpp` 三处 `ThumbDiskCache` 未加 `QuickView::` 限定；`DbgLog` 入参需 `.c_str()`。
- **关键 bug（验收才发现）**：`CacheDir()` 一次性 `CreateDirectoryW("...\QuickView\ThumbCache")` 创建两级目录，父目录 `QuickView` 不存在时失败（`ERROR_PATH_NOT_FOUND`≠`ALREADY_EXISTS`）→ 返回空 → `m_enabled` 恒 false → 缓存**从未生效**（348 次请求全 miss、目录永不建）。修复为逐级 `CreateDirectoryW`（先 `QuickView` 再 `ThumbCache`）。坑：PowerShell `New-Item -Force`/`cmd mkdir` 会自动建多级，掩盖了该 bug；必须用真实 `CreateDirectoryW` 行为验证。
- 链接 `permission denied`：Explorer 加载 DLL + thumbnail-server 拉起 `QuickView.exe` 锁产物。`_build_only.ps1` 改为编译前结束 QuickView 进程 + **移走已注册 DLL**（explorer 后续加载 provider 失败 → 不再拉起 server → EXE 整编译期不被锁）；EXE 兜底重命名解锁 + 失败重试；编译后自动重注册部署。
