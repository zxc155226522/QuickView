## 纠正：CDR「加载中」根因不是 libcdr 不支持 ZIP-CDR
- **推翻先前推断**：先前据文件头 `PK`+`application/x-vnd.corel.z` 反推「libcdr 不认新版 ZIP-CDR、根本解析不了」——**错误**。用户实测新版 exe（含 resvg）拖入 CDR 能打开，老版本打不开；且项目既有结论已写明 libcdr 解析那半一直是好的。
- **正确根因**：libcdr 解析 ZIP-CDR 成功 → 生成含 `<image>`（内嵌位图）的 SVG。老版本用 D2D `ID2D1SvgDocument` 把 SVG 光栅化，它不支持 `<image>`/滤镜/裁剪等 → `CreateSvgDocument` 失败 → 主视图无资源 → 一直「加载中」/空白。新版本把该路径换 resvg（完整 SVG 支持）→ 位图正常显示。代码证据：`main.cpp:11482` 检测 `<image>` 直走 `renderSvgViaResvg`；`11534` D2D 失败安全网也走 resvg；`ImageLoader.cpp:4207` 缩略图 `RasterizeSvgThumbnail` 同样走 resvg。
- **结论**：resvg 集成正是用户要的修复，新版能打开即证明；此前「抽取 ZIP 内 Corel 预览 PNG 作兜底」方案基于错误前提，已作废（resvg 路径保真度更高）。
- **仍待查（未发现根因，勿再猜）**：一次性 `--thumbnail` worker 对 CDR 返回 EXIT=2（已验证新 exe 干净退出、无崩溃）。主视图与缩略图都走同一 `LoadCDR`→resvg，差异仅在缩略图 `RasterizeSvgThumbnail` 在 `scale<1` 时多一道 `QvUpscaleSvgStrokeWidths`（4197）；但该函数只匹配字面 `stroke-width="`，不会破坏 `<image>` data-URI，故**排除描边加粗**为因。EXIT=2 确切原因（libcdr `isSupported` 在 worker 上下文失败？还是 resvg 解析该 SVG 失败？）需实证确认——可能对应资源管理器里 CDR 缩略图「加载中」。

## 新增 `--export-png` 头less 解码转 PNG 工具（用户要求：直接调解码转 PNG 且画布外内容也要显示）
- **入口**：`main.cpp` `TryRunToolProcessFromCommandLine` 新增 `ToolMode::ExportPng` + `RunExportPng(argc,argv)`；用法 `QuickView.exe --export-png <input> <output.png> [maxDim]`。ExitCode：`0`成功 / `2`参数错 / `3`解码失败（HRESULT）。
- **实现**（`ImageLoader.cpp`，`QuickView/` 命名空间）：
  - `ExportToPng(in,out,maxDim=0,whiteBg=true,includeOutsidePage=true)`：`CoInitializeEx(MULTITHREADED)`→`CImageLoader::Initialize(wf)`→`LoadToFrame`→SVG 走 `RenderSvgFrameToBgra`、位图走 `SaveBgraAsPng`；带 `[export]` stderr 调试日志（viewBox/contentBbox/final/raw&rewritten svg head 500B/写成功失败）。
  - `RenderSvgFrameToBgra`：`resvg_parse_tree_from_data` → `resvg_get_image_bbox(tree,&cb)` 取**完整内容包围盒（含越界元素）**；`rx=min(0,cb.x),ry=min(0,cb.y),rw=max(pageW,cb.x+cb.width),rh=max(pageH,cb.y+cb.height)`；**8× 启发式回退**（内容 bbox 比页面大超 8 倍则还原页面矩形，防隐藏/参考线撑爆）；再 `RewriteSvgRootViewBox` 改写根 `<svg>` viewBox 后用 `QvRasterizeSvgResvg`。
  - `RewriteSvgRootViewBox`：改写 viewBox 时**必须删掉根 `<svg>` 的 width/height 属性**（否则 resvg 以 width/height 的 `pt` 单位尺寸作画布 → 把越界内容裁掉，表现为「导出缩小/空白」）；无 viewBox 时退化改 width/height 数值。
  - `SaveBgraAsPng`：WIC `GUID_ContainerFormatPng` BGRA32 编码（复用 LosslessTransform 同款路径）。
  - **安全上限**：`maxDim==0` 时把长边 cap 到 **8192px**（`zoom=cap/max(rw,rh)`），避免 2024版本这类 24k×27k 单位视图框导出时分配 2.6GB 缓冲。用户可用 `--export-png in out 16384` 取更高分辨率。
