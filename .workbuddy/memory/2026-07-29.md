# 2026-07-29 工作日志

## 为 Zhai.PictureView 看图软件增加 PSD / AI / PDF 支持

### 现状（事实为本）
- 项目：.NET 6 WPF 看图软件，已深度集成 Magick.NET 12.3.0。
- PSD/PSB：已在 `PictureSupport.Photoshop` 注册，经 `GetBitmapSourceAsync` 的 default 分支走 Magick 原生解码即可（Magick 原生支持，自动压平图层）。
- AI/PDF：未在支持清单；Magick 读取二者必须委托 Ghostscript，否则解码抛异常返回空。

### 方案（第一性原理 + 优先复用第三方库）
- 统一走 Magick.NET 单管线，不引入第二条解码器。
- PDF/AI 以 `Density=150` 栅格化首页（高清）。
- 打包 Ghostscript 原生库 `gsdll64.dll`（取自本机已装 GS 10.01.2，约 24MB）到 `src/Libs/Ghostscript/`；csproj 将其拷贝至输出根目录；`App.xaml.cs` 启动时设置 `MAGICK_GHOSTSCRIPT_PATH` 指向该 DLL。

### 改动文件
- `src/PictureSupport.cs`：新增 `Illustrator(.ai)`、`PortableDocumentFormat(.pdf)` 类别并入 `All` 与打开对话框滤镜；顺手修正原 JPEG 滤镜行的拼写 bug（误用 Icon 模式）。
- `src/ImageDecoder.cs`：`GetBitmapSourceAsync` 增加 `.psd/.psb/.ai/.pdf` 分支；新增 `GetDocumentBitmapSourceAsync`（高 DPI 文档栅格化）；`GetMagickThumbnail` 支持 density，PDF/AI 缩略图用 150 DPI。
- `src/App.xaml.cs`：新增 `ConfigureGhostscript()` 在 `OnStartup` 配置 GS 路径。
- `src/Zhai.PictureView.csproj`：将 `gsdll64.dll` 作为 Content 拷贝至输出根目录。
- `.gitignore`：新增例外 `!src/Libs/Ghostscript/gsdll64.dll`（覆盖全局 `*.dll` 忽略，使 native 库随仓库发布）。

### 验证
- `dotnet build -c Debug`：0 错误（已消除 CS8632 警告）。
- 写最小控制台用 Magick 实测：PSD 100x80、PDF 200x100、AI 200x100 均成功解码，证明打包的 gsdll64.dll 委托 Ghostscript 生效。
- 输出目录 `bin/Debug/net6.0-windows/gsdll64.dll` 已存在，确认拷贝生效。
