# 2026-08-02 CDR 格式集成方案

## 背景

QuickView(C++23, Direct2D)看图软件需支持 CorelDRAW 矢量格式(.cdr/.cmx)。
CDR 是 CorelDRAW 专有二进制格式,业界唯一成熟开源解析库为 **libcdr**(LibreOffice 维护)。

## 技术选型

| 候选 | 结论 |
|---|---|
| **libcdr** (LibreOffice) | ✅ 唯一可行选择,MPL 2.0,活跃维护,同时支持 CDR + CMX |
| Inkscape | 内部也用 libcdr,无独立能力 |
| uniConvertor/sK1 | Python 实现,不适用 C++ |
| 手动逆向 CDR | 格式极其复杂,不可行 |

## 数据流

```
.cdr/.cmx 文件
  → libcdr::CDRDocument::isSupported()    // 格式检测
  → libcdr::CDRDocument::parse()          // 解析 CDR 二进制
  → librevenge::RVNGSVGDrawingGenerator   // 内置 SVG 生成器(无需自己实现 painter)
  → librevenge::RVNGStringVector           // 输出 SVG XML 字符串
  → RawImageFrame (PixelFormat::SVG_XML)  // 填充帧数据
  → 现有 Direct2D SVG 渲染管线             // 无损缩放,复用已有路径
```

关键发现: librevenge **自带 `RVNGSVGDrawingGenerator`**(在核心库中,非 generators 库),
无需自己实现 `RVNGDrawingInterface` 回调接口。

## API 使用(cdr2xhtml.cpp 参考)

```cpp
librevenge::RVNGFileStream input(filename);     // 注意: 接受 const char*, 非 wchar_t
librevenge::RVNGStringVector output;            // 接收 SVG 输出
librevenge::RVNGSVGDrawingGenerator painter(output, "svg");

if (!libcdr::CDRDocument::isSupported(&input)) {
    if (!libcdr::CMXDocument::isSupported(&input)) {
        // 不支持的版本或加密文件
    } else {
        libcdr::CMXDocument::parse(&input, &painter);
    }
} else {
    libcdr::CDRDocument::parse(&input, &painter);
}
// output[0] 即为 SVG XML 字符串
```

## 集成方式: 源码子项目 + 自写 CMakeLists

与项目已有的 `third_party/unrar-mini` 模式一致,避开 autotools 在 Windows + Clang-cl 下的编译地狱。

### CMake 集成

```cmake
# 主 CMakeLists.txt
add_subdirectory(third_party/librevenge)
add_subdirectory(third_party/libcdr)

target_link_libraries(QuickView PRIVATE
    ...
    librevenge
    libcdr
)
```

### librevenge CMakeLists 关键配置

- 不使用 `project()` 声明(继承主项目编译器设置)
- 降级 C++17: `/clang:-std=c++17`(避免 `shared_ptr::unique()` 在 C++23 移除)
- 强制包含 `win_compat.h`: `/FIwin_compat.h`(定义 S_ISREG/S_ISDIR)
- MSVC 系统 include 注入: `ADAPTIVE_MSVC_INCLUDE_PATHS`
- 编译定义: `LIBREVENGE_BUILD`, `LIBREVENGE_STREAM_BUILD`, `BOOST_ERROR_CODE_HEADER_ONLY`

### libcdr CMakeLists 关键配置

- 不使用 `project()` 声明
- 编译定义: `LIBCDR_BUILD=1`, `BOOST_ERROR_CODE_HEADER_ONLY`, `BOOST_SYSTEM_NO_DEPRECATED`
- ICU stub include 路径: `icu_stub/`(替代 `unicode/*.h`)
- 链接: `librevenge` + `ZLIB::ZLIB`

## 编译兼容性问题全记录

| # | 问题 | 根因 | 解决方案 |
|---|---|---|---|
| 1 | boost-thread `throw` 编译失败 | triplet 对所有端口禁用异常 `/EHs-c-` | triplet 条件添加 `NOT PORT MATCHES "^boost-"` |
| 2 | NASM 中文路径乱码 | 项目路径 `e:\项目\看图软件` 含中文 | 通过 junction `E:\qv_build_tmp` 编译 |
| 3 | `shared_ptr::unique()` 错误 | C++23 移除了此方法 | librevenge 降级 C++17 |
| 4 | `S_ISREG`/`S_ISDIR` 未定义 | POSIX 宏, Windows 不提供 | `win_compat.h` + `/FI` 强制包含 |
| 5 | `unicode/ucsdet.h` 找不到 | libcdr 直接引用 ICU 头文件 | 创建 stub 头文件(空实现) |
| 6 | `zlib.h` 找不到(libcdr) | libcdr 未链接 zlib | CMakeLists 显式 `target_link_libraries(libcdr PUBLIC ZLIB::ZLIB)` |
| 7 | `try/catch` 编译失败 | Release-LTO 禁用异常 | 替换 `std::stof` 为 `strtof` C 风格 |
| 8 | librevenge `stdio.h` 找不到 | 子项目未继承 MSVC 系统 include | `target_include_directories(SYSTEM ${ADAPTIVE_MSVC_INCLUDE_PATHS})` |
| 9 | `UCharsetDetector` 类型未知 | stub 头文件遗漏 | 补全 stub 定义 |
| 10 | `U8_APPEND_UNSAFE` 未定义 | stub 头文件遗漏 | 在 `utf8.h` 中添加宏实现 |

## 后续注意事项

1. **ICU 功能降级**: 字符集检测和 CJK 编码转换为空实现,对使用标准编码的 CDR 文件无影响;如需完整 ICU 支持,在 vcpkg.json 添加 `icu` 依赖并删除 `icu_stub/` 目录
2. **多页 CDR**: 当前只取第一页(`svgPages[0]`),多页文档后续可纵向拼接
3. **加密 CDR**: libcdr 不支持加密文件,会返回 `E_FAIL` 并显示 "Unsupported/Encrypted"
4. **SVG 消毒**: libcdr 生成的 SVG 直接传递给 D2D SVG 引擎,未经过原生 SVG 的 ID 消毒/Style Inliner;如遇渲染异常,可考虑将 CDR 生成的 SVG 也走 SVG 消毒逻辑
5. **boost 编译**: 首次构建 boost 需 ~10 分钟(80+ 组件),后续编译走 binary cache 秒级完成
